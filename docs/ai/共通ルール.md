# AI共通ルール

## 対象

Claude、ChatGPT/Copilot、Geminiが同じ判断をするための共通規範。個別AIの
入口ファイルからこの文書を参照する。

## 仕様とデータ

- アプリ名は `3DprintingDB`。対象はフィラメント情報の登録・閲覧・比較。
- 外部データの出典は `https://3dfilamentprofiles.com/`。取得処理を追加する際は
  サイトの規約を確認し、スクレイピングを無断で実装しない。
- 推奨ノズル温度・ベッド温度・乾燥温度・乾燥時間は「推奨」と表示し、
  ユーザーの変更値とは別に扱う。
- 個人の作品画像は製品画像と別の保存領域・参照先として扱う。

## UI

- グレーブルーを基調に、低彩度・低輝度のモダンな配色を守る。
- 日本語ゴシック系の読みやすさを優先し、文字サイズ変更に対応する。
- 一覧のヘッダー（設定、比較、列タイトル）はスクロールで隠さない。
- 比較は一覧のチェックボックスから遷移し、10項目以上をレーダー表示する。

## 安全性と品質

- 秘密情報、個人画像、生成バイナリをコミットしない。
- 既存機能を壊す変更は避け、変更理由を要件・計画・テスト仕様に反映する。
- 判断不能な仕様は実装前に確認し、テスト不能な部分は未検証として報告する。
