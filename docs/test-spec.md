# 3DprintingDB テスト仕様

## 自動検証

- `npm run typecheck` — TypeScriptの型エラーがないこと。
- `npx expo export --platform web` — Expoバンドルが生成できること。

## UI確認

1. 一覧に登録データが表示され、左端チェックボックスを複数選択できる。
2. 行タップで詳細へ移動し、製品画像・推奨値・乾燥条件が表示される。
3. 設定で表示項目と文字サイズを変えると一覧へ反映される。
4. 比較ボタンで選択済みデータの比較画面へ移動できる。
5. 比較項目が12項目表示され、未選択時は空状態を表示する。
6. 作品画像URLを保存し、詳細画面で別画像として表示できる。
7. 画面をスクロールしても一覧ヘッダーが残る。
8. アプリを再起動しても保存したデータが残る。
