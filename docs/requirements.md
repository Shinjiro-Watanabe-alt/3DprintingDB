# 3DprintingDB 要件定義

## 1. 目的

`3dfilamentprofiles.com` のフィラメント情報を端末に保存し、推奨印刷条件を
確認しながら自分の設定・作品例を管理する。

## 2. 画面要件

1. 初期画面は登録フィラメント一覧。行タップで詳細を表示する。
2. 一覧の左端にチェックボックスを置き、上部の比較ボタンから比較画面へ遷移する。
3. 一覧上部の設定から表示項目、文字サイズ、表示トーンを変更できる。
4. 設定・比較ボタン・列タイトルは一覧スクロール中も固定する。
5. 詳細には製品画像、印刷条件、推奨乾燥温度・時間、作品例画像を表示する。
6. 比較画面は選択した複数フィラメントを、設定された10項目以上のレーダーで比較する。

## 3. データ要件

製品名、メーカー、素材、色、線径、推奨ノズル温度、推奨ベッド温度、
推奨乾燥温度・時間、出典、製品画像、作品例画像、比較指標を保持する。
推奨値は初期値として入力欄に表示するが、ユーザー編集値と区別する。

## 4. デザイン

低彩度グレーブルー、モダンな日本語ゴシック系、カードと余白を使った画面。
端末の明るさ・アクセシビリティ設定を阻害しない。

## 5. 対象外

カレンダー転記、OCR、Googleカレンダー連携など、handover kitに含まれる
別プロジェクトの要件は採用しない。
