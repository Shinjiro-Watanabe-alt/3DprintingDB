# 3DprintingDB 実装計画

## Phase 1: UIとローカルデータ

- Expo + React Native + TypeScriptでAndroid/iOS共通画面を作る。
- サンプルフィラメントを型付きデータとして定義する。
- 一覧、詳細、設定、チェック選択、比較導線を実装する。
- AsyncStorageで端末内保存を行う。

## Phase 2: データ同期

- 公式に利用可能なデータ取得方法を確認する。
- 出典URL・取得日時・ライセンス情報を持つインポート形式を決める。
- 失敗時は既存のローカルデータを保持する。

## Phase 3: 画像・比較品質

- 製品画像と作品例画像の保存領域を分離する。
- レーダー描画をSVG等の既存互換ライブラリで強化する。
- 文字サイズ、スクロール固定、空状態、長い商品名を実機確認する。

## 完了条件

Android/iOSで一覧から詳細・設定・比較まで操作でき、アプリ再起動後も
保存データが残り、テスト仕様の主要ケースを通過する。
